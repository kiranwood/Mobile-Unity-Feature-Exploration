# Unity Feature Explorer

**PG29 Mobile Development 4**

## About the Project


This project is to continue off where we left off in the ball tilting game and add one more feature into the game.


### What I did:


I decided to create a simple ball game with the tilting and the pinching feature that will make the ball smaller / bigger. The goal of the game is to move the ball all the way to the end by tilting the phone. Players can pinch to change the size of the ball to let it squeeze through tighter spaces or to be bigger and avoid falling into a hole. I also added a timer that tracks how long it takes you to get to the end. The game resets the ball to the beginning if the player balls or hits a red wall. At the end in the win screen, it shows the players current time and its best time. There is also a main menu to play and quit the game.

### How to play:


`Tilt your phone` - To move the ball

`Pinch your screen` - To make the ball smaller or bigger


## How to add pipeline to own unity project


**Step 1**- Clone the repo to your desktop


**Step 2** - Make sure to have Unity 6.3.8 downloaded


**Step 3** - Add the project from your cloned repo


**Step 4** - If not already downloaded, download either Android or IOS platform and set it as your current platform.


**Step 5**- Connect your phone or a virtual device to your machine


**Step 6** - Inside editor device make sure to have either `any android device` or `any ios device` picked.


**Step 7** - Press play. If the tilting is inverted, go to the player and change the invert settings to match your device
